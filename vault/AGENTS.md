# Geo-Invert: instructions for AI coding tools

Project context lives in the Obsidian vault at `vault/`. Read `vault/00 Index.md` first, then `vault/08 AI Working Rules.md` before changing code.

Short version:
- Work on a branch `task/<name>`; do not commit to `main` and do not push.
- Follow the active task brief in `vault/`. Touch only the files it names.
- Never write custom inversion math; pyGIMLi does inversion.
- Report real command output; don't claim things work without running them.
- Finish with a review request using `vault/Templates/Review Request.md`.
